# Module 2: Vibe Coding starter

NUS AIDF AI Academy · Saturday 14 November 2026

## Start here
1. Open the **Claude** panel (the Claude icon in the left or right sidebar).
2. The first time, it asks whether to use your API key: choose **Yes**.
3. Check the model at the bottom of the prompt box says **Haiku**.
4. Type your first instruction from the slide and press Enter.

## See your app
In the terminal (menu **Terminal → New Terminal**):

```
python3 -m http.server 8000
```

Click **Open in Browser** when the pop-up appears. Refresh that tab after every change.

## Which model when?
| Task | Model |
|---|---|
| Writing and changing code (most of the time) | **Claude Haiku** |
| Planning a feature, stuck on a bug, a big change | **Claude Sonnet** |
| Comparison activity only | **Codex (GPT-6 Luna)** |

## Golden rules
- One change → test → **commit** → next change.
- Never paste an API key or password into any file or chat.
- Made-up data only. "For learning only. Not financial advice."
